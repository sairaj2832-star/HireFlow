## What went wrong (plan deviations, all resolved)

1. **No git repo** — plan assumed one. Did `git init` in place (worktree isolation impossible).
2. **Dropped `asyncio_mode=strict`** from `pyproject.toml` — no async tests in B0, avoids missing-plugin warning.
3. **`dict` → `dict[str, Any]`** in `ledger.py`/`ledger_store.py`/`migrate.py` — mypy strict requires type params.
4. **`import yaml  # type: ignore[import-untyped]`** — no PyYAML stubs; avoided adding `types-PyYAML` (frozen stack).
5. **FTS5 `tokenize='unicode61 "remove_diacritics 2"'` rejected** by SQLite 3.43.1 (`parse error in tokenize directive`) → plain `unicode61`. Revisit in B6 if diacritics matter.
6. **Trigger errors are `IntegrityError`, not `OperationalError`** — `RAISE(ABORT,…)` surfaces as IntegrityError; tests catch `sqlite3.Error` + `try/finally` close (Windows file-lock cleanup turned the leak into a masking `NotADirectoryError`).
7. **Parameterized test INSERTs** — plan's `'a'*64` SQL literal would violate the 64-char `sha256` CHECK.
8. **`verify.ps1` hardened** — uses `.venv` binaries w/ PATH fallback, migrates before WAL check; `test_verify_gate` deselects itself (plan's version re-ran the suite recursively = fork-bomb).
9. **Frontend hand-scaffolded** (no `npm create vite` network dep) + added `.eslintrc.cjs`/`index.css` the plan omitted but `lint`/`build` require.
10. **`/health` reports real WAL** via file-relative db path (plan's CWD-relative path breaks under TestClient).
